# 메인 가이드 MD 작성 및 다듬기 규칙 (`GUIDE_STYLE_RULES.md`)

본 문서는 `xtron-manual` 프로젝트의 공식 제공용 매뉴얼(`src/data/markdown/**/*.md`)을 작성하거나 다듬을 때, 모든 에이전트와 작업자가 일관되게 따라야 하는 표준 규칙입니다.  
기준 레퍼런스는 `Status = Deploy`인 [kickstand-TypeA.md](../src/data/markdown/parts/kickstand-TypeA.md) 및 [pedal.md](../src/data/markdown/parts/pedal.md)입니다.

---

## 1. 핵심 원칙: 「글 → 그림」 순서 & 초간결 지시
- **배치 순서**: 반드시 **`짧은 1줄 행위 지시(글)` → `2D 일러스트(그림)`** 순서를 지킵니다.
- **문장 길이 제한**: 1단계 설명은 **1~2문장(40~60자 이내)**으로 제한합니다. 배경 설명이나 장황한 수식어("돌덩이처럼 단단하다면...", "편리하게 사용할 수 있습니다")는 제거합니다.
- **글 최소화 · 그림 최대화**: 2D 일러스트만 보고도 행위를 이해할 수 있도록 글은 핵심 동작("어디에 무엇을 어떻게")만 남깁니다.

## 2. 이미지 배치 규칙 (R2 & Placeholder)
- **1동작 = 1이미지 원칙**: 한 단계나 항목 안에 동작·대상이 2개 이상(예: *레버 당기기* + *패드/로터 마모 확인*)이라면, **이미지 자리도 반드시 2장 이상**으로 분리해 배치합니다.
- **미완성 이미지 자리 표시**: 아직 실제 R2 일러스트가 없는 행위 묘사 위치에는 `https://placehold.co/600x350?text=...` (또는 `600x400`)를 사용해 **어떤 장면을 그려야 할지 `![대체 텍스트]`와 URL에 간략히 묘사**해 둡니다.
- **기존 임시 경로 존중**: 이미 파일 내에 임시로 지정된 R2/드라이브 경로(예: `xtron-guide/...`)가 있다면, 사용자가 요청하지 않는 한 임의로 삭제하거나 수정하지 않습니다.

## 3. 문서 표준 구조 (4단 템플릿)
1. **상단 안전 경고**: `> [!CAUTION]` (평평한 곳 거치, 전원 차단·배터리 분리 등)
2. **준비물 / 대상 확인**: `#### 1. 필요한 준비물` (간단 불릿 또는 비교 표)
3. **단계별 동작**: `**❶ 동작 제목**` + 1줄 지시 + 2D 일러스트
4. **최종 점검 / 주의사항**: `> [!WARNING]` 또는 `> [!TIP]` (+ 필요시 `.md-btn-kakao` / `.md-btn-dealer` CTA 버튼)

## 4. 문법 및 서식 제한 (GFM 순수화)
- **불필요한 HTML 금지**: `<div align="center">`, `<img style=...>`, `<b>`, `<font>`, 문장 중간의 과도한 `<br>`을 사용하지 않습니다. *(단, `.md-cta-container` 버튼 블록과 `VideoPlayer`용 예외 제외)*
- **중복 아이콘 금지**: `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]` 내부에는 사이트가 이미 아이콘과 라벨을 자동 렌더링하므로 `⚠️`, `🚨`, `💡`, `ℹ️` 이모지를 중복 작성하지 않습니다.
- **단일 주제 분리 원칙**: 하나의 제품/부품이라도 장착 위치나 방식이 2가지 이상(예: 전면 vs 후면, 타입A vs 타입B)으로 나뉘어 이미지가 많아지면 **독립된 MD 문서와 시트 행으로 분리**합니다.
