#### 1. 배터리가 올바르게 장착되었는지 확인합니다.
   
![잘못 장착된 예시](project/xtron-guide/basic/step_01-1.webp)

#### 2. 배터리 외부의 ON/OFF 버튼을 확인합니다.

![배터리 버튼 확대](project/xtron-guide/basic/step_02.webp)
