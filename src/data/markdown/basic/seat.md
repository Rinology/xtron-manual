#### 올바른 안장 높이 찾는 법

1. **고정 자세 잡기**
   평평한 곳에서 벽이나 기둥을 짚고 자전거가 넘어지지 않게 고정한 뒤 안장에 앉습니다.
2. **페달 위치(크랭크 각도) 설정**
측정할 쪽 페달을 가장 아래쪽(6시 방향)으로 내립니다.
*(※ 크랭크 암과 시트포스트가 일직선이 되는 위치가 기준입니다.)*
4. **발 뒤꿈치 확인 (측정 시)**
   신발을 신고 발 뒤꿈치를 페달 중심에 얹었을 때, 무릎이 완전히 쫙 펴지는 높이가 적당합니다.
5. **발 앞꿈치 확인(주행 시)**
   실제 주행 시에는 발 앞꿈치(볼록 나온 뼈 부위)를 페달에 올리며, 페달을 밟았을 때 무릎이 약 15~20도 정도 살짝 굽혀지는 각도가 완벽합니다.
