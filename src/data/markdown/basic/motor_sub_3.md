**\[ Motor position sensor fault! ] : 모터 위치 센서 오류**



원인: 모터 커넥터가 헐겁게 체결됨



해결 방법: 커넥터를 단단히 다시 체결해 봅니다. 조치 후에도 해당 에러 코드가 지속된다면 모터 점검(센서 교체 혹은 모터 코어 교체)이 필요합니다.

**\[ Motor or controller short circuit fault! ] : 모터 또는 컨트롤러 합선 오류**



원인: 컨트롤러 고장



해결 방법: 컨트롤러 교체가 필요합니다.

**\[ THROTTLE fault! ] : 스로틀 오류**



원인: 스로틀이 눌린 상태에서 전원이 켜짐



해결 방법: 스로틀이 눌리지 않도록 위치나 각도를 조정합니다.



참고: 스로틀 자체에 물리적인 문제가 없다면, 간혹 컨트롤러가 원인인 경우도 있으니 점검이 필요합니다.

\[**에러 메시지 없이 작동하지 않는 경우]**

1. 브레이크 센서 간섭

&#x20;상태: 브레이크가 잡힌 것으로 인식되어 모터 작동이 차단됨

&#x20;해결: 브레이크 인식이 해제되도록 센서 위치를 조정합니다. 조정이 어렵다면 임시로 센서 커넥터를 분리해 보세요.



2\. PAS 인식 불가

&#x20;상태: 페달을 돌려도 계기판에 'PAS' 글자가 안 뜸

&#x20;해결: 파스 센서가 BB(크랭크 축)에서 이탈했거나 고장 난 상태입니다. 센서를 BB에 밀착시켜 고정해 보고, 그래도 안 되면 파스 센서 교체가 필요합니다.


3. THROTTLE 인식 불가
 상태: 스로틀을 누를 때 계기판에 'THROTTLE' 글자가 표시되지 않음
 해결: 스로틀 레버 혹은 버스 케이블에 문제가 발생한 상태입니다. 스로틀 레버나 버스 케이블을 교체하여 테스트해 보아야 합니다.

4. 모터 헛돔 (소리만 남)

&#x20;상태: 모터 도는 소리는 나지만 바퀴(휠)가 회전하지 않음

&#x20;해결: 모터 내부의 유성 기어가 심각하게 파손된 상태입니다. 유성 기어 교체가 필요합니다.



5\. 배터리 잔량 0 표시

&#x20;상태: 실제 배터리가 있는데도 계기판 잔량 게이지가 '0'으로 뜸

&#x20;해결: 컨트롤러 불량으로 인한 증상이므로 컨트롤러 교체가 필요합니다.
